This is the deliverable that keeps you paid. Everything you built across the gig — the baseline, the local work, the on-page fixes, the Ads — is invisible to the client until you *report* it. In this assignment you produce the two artefacts that make your value undeniable: a **live Looker Studio dashboard** and a **short monthly report** built on it, for your real capstone client. Together they're the centrepiece of your portfolio case study.

## The brief

Produce, for your capstone client, a complete reporting package:

- A **client-ready Looker Studio dashboard**, wired to GA4 and Search Console (plus Google Ads if it's running), showing **business outcomes** (leads, calls, WhatsApp, forms, cost per lead) — not vanity metrics — and comparing the current period against the **baseline** you captured in Module 4.
- A **one-to-two-page monthly report** using the five-beat template (headline → what we did → what happened → what it means → what's next), leading with the win and honest about any miss.
- **Results-call talking points** ready to present it out loud.

No live client yet? Use the Simulated Client fallback below — the work is identical.

## Steps / checklist

1. **Sort access**, then build the dashboard. Confirm you can see the client's GA4, Search Console (and Ads). Connect each with its native connector.
2. **Add the essential tiles:** scorecard row (total leads, calls, WhatsApp, cost per lead), leads-over-time, channel breakdown, top pages, top queries + position, ad spend vs conversions/CPL. Add GBP calls via a Google Sheet if you're tracking them.
3. **Turn on compare-to-previous-period**, set a sensible default date range, and **brand it** (logo, client name, plain-English labels).
4. **Set view-only sharing** and get the live link.
5. **Write the monthly report** from the swipe template. Headline sentence in money language *first*. Translate leads to rupees using the client's close rate and job value. Include one honest note + fix.
6. **Prepare results-call talking points:** headline, baseline-vs-now, two tiles to narrate, the honest note, and your one-sentence next-step ask. Rehearse the "why isn't it working yet?" answer.

- **The dashboard:** a shared live link (view access) plus 2–3 screenshots for your records/portfolio.

## Self-assessment rubric

Grade honestly. "Client-ready" means you'd send it to a paying owner today.

| Criterion | Missing | Getting there | Client-ready |
|---|---|---|---|
| **Dashboard shows business outcomes** | Only sessions/impressions/rankings | Leads present but buried below vanity tiles | Money metrics (calls/WhatsApp/forms/CPL) headline the top, jargon-free labels |
| **Compared to baseline** | No comparison at all | Compare-to-previous on, but no tie to the Module 4 baseline | Current period shown clearly against the baseline and the agreed goal |
| **Report tells a clear, honest story** | Data dump or 40-slide deck | Has a narrative but leads with process, or hides the miss | Five-beat structure, money-language headline first, one honest miss + fix, reads in ~2 min |
| **No vanity-only metrics** | Report is rankings/impressions with no money link | Some metrics connected, some floating | Every metric passes the "so what?" test and ties to leads/rupees |

If any row sits in "Missing" or "Getting there," revisit that lesson before you call it done. A confusing report undersells great work — and to the client, the report *is* the work.
