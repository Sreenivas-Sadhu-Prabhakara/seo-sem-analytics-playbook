Theory's over. This is where the module earns its keep — and where your capstone report gets the "before and after" it needs.

## The brief

For your **capstone client**, you'll deliver two things:

1. **Optimised priority pages** — the top **3–5 money pages**, rewritten using this module's templates so they rank *and* convert.
2. **A 90-day content plan** — a realistic content calendar the client (or you, on retainer) can actually execute.

If you have site access, make the edits live or in a staging copy. If you don't, deliver a **page-by-page recommendation doc** — current element → recommended rewrite → why. Both are legitimate, sellable deliverables; the recommendation doc is often how the real engagement starts.

## Steps / checklist

**1. Pick the money pages (from your strategy).**
Pull your keyword/intent map from Module 3 and choose the **3–5 pages/keywords** that matter most — usually the core service pages and, if multi-branch, the location pages. These are where leads come from, so these get optimised first.

**2. Rewrite the on-page elements.**
For each page, apply the Lesson 1 checklist:

- [ ] **Title tag** — `Keyword + Locality | Brand`, 50–60 chars, unique per page.
- [ ] **Meta description** — 140–160 chars, benefit + locality + CTA.
- [ ] **One H1** matching the page's promise + a logical H2/H3 outline.
- [ ] **URL slug** — short, readable, keyword-bearing (only change live URLs if you can redirect).
- [ ] **Body copy** — target keyword placed naturally, no stuffing; scannable structure.
- [ ] **Internal links** with descriptive anchor text out to relevant service pages.
- [ ] **Image filenames + alt text** — real, descriptive.

**3. Make each page use the money-page template + a clear local CTA.**
Apply the Lesson 2 service-page template (problem → solution → proof → details → FAQs → CTA → NAP/map). Every page must have **one clear, above-the-fold, mobile-first CTA** — call / WhatsApp / book (Lesson 3). Location pages must be genuinely unique, never doorway spam.

**4. Run the trust pass.**
Score each page against the Lesson 5 trust audit — named practitioners, real photos, reviews on-page, NAP, HTTPS. Note the top trust fixes, especially if it's a YMYL niche.

**5. Build the 90-day content calendar.**
A simple table planning ~**8–12 pieces over 3 months**: mostly the optimised/new **service and location pages**, plus a few **intent-matched articles** (informational, top-of-funnel, each routed to a money page). For each row: topic, target keyword, intent, page type, primary CTA, and target month. Keep it *realistic* — a solo owner won't publish twice a week; better to promise six great pieces than twenty ghost ones.

## Self-assessment rubric

| Criterion | Missing | Getting there | Client-ready |
| --- | --- | --- | --- |
| **Titles / meta / headings** | Default or duplicated titles; blank meta; no H1 discipline | Some rewritten; a few gaps or duplicates remain | Every page: unique `Keyword+Locality\|Brand` title, custom meta, one H1, clean outline |
| **Money pages + CTAs** | Vague pages, no clear CTA | Template partly applied; CTA present but buried or weak | Full template; one clear, above-the-fold, mobile-first local CTA per page |
| **Intent match** | Wrong page type for the query | Mostly matched; one or two mismatches | Every page/article matched to its search intent and routed to a money page |
| **Trust / E-E-A-T** | Faceless, stock photos, no NAP | Some real signals added | Named experts, real photos, reviews on-page, NAP + map, HTTPS |
| **Content calendar** | None, or a wishlist of 30 vanity posts | A plan, but unrealistic or unmatched to intent | 8–12 realistic, intent-matched pieces over 90 days, each with keyword + CTA |

Grade honestly. Every "Missing" or "Getting there" is your next hour of work — do it before you show the client.
